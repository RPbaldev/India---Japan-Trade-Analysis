# India–Japan Trade Intelligence & Product Opportunity Analysis

Excel-based business analytics project using **India–Japan import and export trade data sourced from the International Trade Centre (ITC)**.

The project covers data cleaning, HS6 product identification, product/category mapping, trade trend analysis, top product analysis, and high-growth product analysis. Product categories were selected based on practical experience in wholesale and retail operations.

# Overview

This project examines trade trends, product-level performance, category contribution, and high-growth opportunities in India–Japan trade, with product scope informed by hands-on B2B/B2C wholesale and retail experience.

# Workflow

ITC Trade Data → Data Cleaning → HS6 Identification → Product Mapping → Trade Analysis → Growth Analysis → Business Interpretation

### Files

* `01_ITC_Trade_Data_Raw.xlsx` — Raw trade data
* `02_ITC_Trade_Data_Cleaned.xlsx` — Cleaned data
* `03_HS_Code_Reference.xlsx` — Selected HS6 codes
* `04_Product_Mapping.xlsx` — Product/category mapping
* `05_ITC_Trade_Data_Analysis.xlsx` — Final analysis
* `Project_Documentation.pdf` — Detailed project documentation

**Tools:** Microsoft Excel | ITC Trade Data | HS6 Classification | Business Analysis
